# MySquire Frontend

Frontend do **MySquire**, uma aplicação desenvolvida para facilitar a entrada de novos jogadores no universo do RPG de mesa e auxiliar jogadores experientes no gerenciamento de seus personagens.

A aplicação centraliza todas as informações de um personagem em um único ambiente intuitivo, tornando a experiência mais organizada e acessível.

---

# Problema

Apesar da crescente popularidade dos RPGs de mesa, muitas pessoas deixam de jogar por enfrentarem dificuldades como:

- Medo de cometer erros durante a partida;
- Dificuldade em compreender as regras dos sistemas de RPG;
- Excesso de informações distribuídas entre fichas, livros e anotações;
- Organização complicada de equipamentos, magias, mapas e atributos.

O MySquire foi criado para reduzir essa complexidade, oferecendo uma ferramenta que auxilia o jogador durante toda a campanha.

---

# Público-alvo

- Pessoas que desejam começar a jogar RPG de mesa.
- Jogadores iniciantes.
- Jogadores experientes que buscam organizar suas campanhas.
- Mestres que desejam auxiliar seus jogadores.

# Solução

O MySquire reúne os principais recursos necessários para acompanhar um personagem durante uma campanha de RPG.

## Funcionalidades

- Criação  de personagens
- Gerenciamento de atributos
- Controle de equipamentos
- Sistema de magias
- Visualização e interação com mapas
- Área de anotações
- Integração com API para persistência dos dados

# Como executar

## Clone o repositório

```bash
git clone https://github.com/seu-usuario/mysquire-frontend.git
```

Entre na pasta do projeto.

```bash
cd mysquire-frontend
```

Instale as dependências.

```bash
npm install
```

Execute a aplicação.

```bash
npm run dev
```
